Title: 6 Documents to Have Before Vibe Coding a Website

1. linuxjourney.com 
Teaches linux in a gamified, bite sized way

2. overthewire.org/wargames/
After getting basic skills on linuxjourney.com, proceed to this website which allows you ssh into a box via a puzzle that forces you to use real linux commands

3. Use the keyword "man" followed by the specific command to let you read information about it

4. Using the keyword "tldr" followed by the specific command gives you a quick summary of the command followed by a few examples

5. pip install yt-dlp and then yt-dlp "video-url"
These commands install a youtube video downloader which automatically downloads the version with the best available quality
